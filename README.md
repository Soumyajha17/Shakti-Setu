# Shakti Setu – Android Application

Shakti Setu is an Android application developed to provide users with a platform to explore job opportunities, manage applications, and access related services through a mobile interface.

## Features

- **User Interface:** Android screens designed using XML.
- **Job Details:** View information about available opportunities.
- **Applications:** Access application-related functionality.
- **Bookings and Payments:** Dedicated screens for booking and payment workflows.
- **Notifications:** Notification-related functionality.
- **Chat:** A dedicated chat interface.
- **User Authentication:** Authentication-related screens, including OTP functionality.

## Tech Stack

- **Language:** Java
- **UI Design:** XML
- **Development Environment:** Android Studio
- **Build System:** Gradle
- **Backend/Database:** Firebase and/or other components as configured in the project

## Getting Started

1. Clone or download this repository.
2. Open Android Studio.
3. Select **Open** and choose the project folder.
4. Allow Gradle to sync and download the required dependencies.
5. Configure any required backend services or API credentials locally.
6. Run the application on an Android emulator or a compatible Android device.

## Requirements

- Android Studio
- Android SDK compatible with the project configuration
- Java/JDK version compatible with the Gradle configuration
